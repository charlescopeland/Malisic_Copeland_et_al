# RNAseq
Scripts to analyze RNAseq reads, including filtering, alignment, featureCounts, and analysis downstream of DESeq2

Scripts for hierarchical clustering of gene sets

Scripts for GOterm analysis

Scripts for bacterial phylogenetic analysis using AMPHORA2

To run these scripts, the following software and libraries must be installed:

1. Python Libraries
pandas
numpy
matplotlib
scipy
biopython
requests
lxml
openpyxl

2. R Packages
sva
DESeq2
ggplot2
tidyverse
limma
foreach
stringr
readxl
topGO

3. External Bioinformatics Software
HISAT2
Samtools
FastTree
fastp
subread (featureCounts)
NCBI BLAST+
MarkerAlignTrim.pl
